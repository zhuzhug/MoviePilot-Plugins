# 媒体库清理 (LibraryCleaner)

扫描媒体库和下载目录，检测残留文件并提供安全的清理方案。

## 检测能力

| 分类 | 说明 | 安全等级 |
|------|------|----------|
| 悬空软链 | 软链目标已不存在 | ✅ 安全可删 |
| 孤儿元数据 | 无对应视频的 .nfo/.jpg/.srt | ✅ 安全可删 |
| 空目录 | 无任何文件的目录 | ✅ 安全可删 |
| 重复资源 | 同片不同版本 | ⚠️ 需确认 |
| 已入库源文件 | 下载目录中已整理到库的文件 | 🔴 谨慎 |
| 孤立源文件 | 无下载任务跟踪 | 🔴 谨慎 |
| 源目录空目录 | 下载目录中的空文件夹 | ✅ 安全可删 |

## 配置项

- `scan_dirs`：扫描目录（默认读取媒体库目录）
- `scan_scope`：扫描范围（media_only / source_only / all）
- `enable_*`：各检测项开关
- `protected_dirs`：保护目录（不删除）
- `max_display_per_type`：每类展示上限
- `allow_delete`：是否启用删除功能
- `cron`：定时扫描计划

## 使用注意

1. 首次使用请先扫描，查看各类残留情况
2. 安全等级为"谨慎"的项目请逐条确认后再删除
3. 已启用删除功能后，每条数据和每个分类都有删除按钮
4. 扫描支持异步执行，可随时取消
