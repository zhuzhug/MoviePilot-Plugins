# 源文件清理 (SourceCleaner)

扫描下载目录，检测残留文件并提供安全的清理方案。

## 功能

- Vue 前端，进度条 + 自动刷新
- 侧栏导航入口
- 仪表板自动刷新
- 安全分级标签（✅安全/⚠️需确认/🔴谨慎）
- 单条删除 + 批量删除
- 异步扫描 + 取消功能

## 检测分类

| 分类 | 安全等级 | 说明 |
|------|----------|------|
| 悬空软链 | ✅ 安全可删 | 软链目标已不存在 |
| 孤儿元数据 | ✅ 安全可删 | 无对应视频的 .nfo/.jpg/.srt |
| 空目录 | ✅ 安全可删 | 空目录可直接删除 |
| 重复资源 | ⚠️ 需确认 | 同片不同版本 |
| 已入库源文件 | 🔴 谨慎 | 已整理到媒体库的文件 |
| 孤立源文件 | 🔴 谨慎 | 无下载任务跟踪 |
| 源目录空目录 | ✅ 安全可删 | 下载目录空文件夹 |
| 源文件重复 | ⚠️ 需确认 | 下载目录重复文件 |

## 构建前端

需要 Node.js 20+：

```bash
cd plugins.v2/librarycleaner
npm install
npm run build
```

构建产物输出到 `dist/assets/`。

## GitHub Actions

推送到 main 分支时，`.github/workflows/build.yml` 会自动构建 Vue 前端并提交编译产物。
