# MediaGarbageCleaner（资源清理）

扫描媒体库与下载目录中的垃圾文件，支持按分类清理，删除前强制经过两级确认。

## 主要功能

- **断链软链接**：遍历媒体库，查找指向不存在目标的符号链接。
- **硬链接**：查找 `st_nlink > 1` 的冗余硬链接（辅种/整理产生的副本）。
- **重复文件**：两阶段聚类（先按大小分组，再按头部+尾部+大小签名），标注同组份数与建议保留。
- **空目录**：查找媒体库中的空文件夹。
- **失败整理记录**：查询整理历史中失败状态的记录，仅删除记录本身。
- **孤儿 strm**：源目录已删除但媒体库仍有残留的 strm，可按保留网盘或源目录比对过滤。
- **未整理资源**：扫描下载目录中从未经整理过的媒体文件，按修改时间排序。

## 防误删机制

- **两级确认**：删除前需经过「发起 → 继续确认 → 最终确认」，三个删除入口（单条/批量/全部）均受此约束，未确认一律拒绝。
- **整理记录反查**：未整理资源删除前强制反查整理历史，文件只要曾出现过（无论成功失败）即拒绝删除；查库失败时保守拒绝。
- **下载器在册豁免**：仍在做种或下载的文件即使无整理记录也不视为垃圾。
- **保留路径标记**：路径任一层命中保留关键词（内置勿删/保种/契约/勿动等）即永久豁免，扫描不出候选、删除强制拒绝。
- **可恢复删除**：默认走回收站，可配置关闭。
- **扫描容错**：各分类独立捕获异常，单类失败降级为空列表，不影响其它分类。

## 配置项

| 参数 | 说明 |
| --- | --- |
| `enabled` | 启用插件 |
| `exclude_dirs` | 排除目录列表（断链/硬链/重复/空目录扫描生效） |
| `dup_only_video` | 重复检测仅限视频类（默认开启） |
| `protect_name_keywords` | 保护作品名称（`\|` 分隔，不区分大小写） |
| `orphan_scan_enabled` | 启用孤儿 strm 扫描 |
| `orphan_scan_source_dirs` | 孤儿扫描的源目录（用于父目录名比对） |
| `orphan_scan_keep_disks` | 孤儿扫描保留的网盘名关键词 |
| `untransfer_scan_enabled` | 启用下载目录未整理资源扫描 |
| `untransfer_exclude_dirs` | 未整理扫描排除目录 |
| `untransfer_exclude_keywords` | 未整理扫描排除关键词 |
| `delete_to_trash` | 删除走回收站（默认开启，可恢复） |
| `reserved_keywords` | 额外保留关键词（`\|` 分隔） |

## 使用建议

- 先扫描确认结果，再执行清理。
- 清理断链/孤儿 strm 前建议先确认源文件是被有意删除的，避免同类清理误删在用资源。
- 重复文件每组至少保留一份（页面已标注"建议保留"）。
- 未整理扫描会跳过下载器在册文件与 1MB 以下样本文件。
