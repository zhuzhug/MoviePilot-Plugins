# MoviePilot-Plugins

个人维护的 MoviePilot 第三方插件仓库，当前收录 4 个插件。

## 订阅本仓库

在 MoviePilot 中打开 **设定 → 插件 → 插件市场**，添加以下地址：

```
https://github.com/zhuzhug/MoviePilot-Plugins
```

刷新后即可在插件市场中检索并安装本仓库提供的插件。

## 插件列表

### AI双引擎识别（AIPair）v1.0.22

原生识别失败时做 AI 结构化兜底（救当次），成功后沉淀窄作用域识别词（救以后），让同类资源以后原生直接识别。识别词写入走全量快照比对、只增不删、写后逐行校验，杜绝清空用户已有识别词。致谢 [liuyuexi1987](https://github.com/liuyuexi1987) 的开源识别增强实现。

**主要功能**

- **同步兜底识别**：`ChainEventType.NameRecognize` 事件回调里同步跑 LLM 猜测 + TMDB 硬校验，把结果写回 event_data，让 MoviePilot 原生链路继续二次识别，直接救当次整理。
- **窄作用域识别词沉淀**：兜底成功后自动生成窄作用域识别词（分组头 + 作品标记 + 带 TMDB ID 强制绑定的规则行），带 AI 来源标记；写后回放验证，命中数据库 ID / 标题 / 年份+类型 / 季集任一即通过。
- **省 token 三防线**：仅原生识别失败才触发（成功零消耗）；冷却期拦截同 title+path 短期重复；同名去重（30 天过期）拦截同剧多集重复调 LLM。
- **垃圾样本预判**：纯字幕文件、强乱码文件名直接跳过不调 AI。
- **生效目录路径过滤**：默认只处理 `/media/downloads` 下的资源，订阅/搜索类的 title-only 事件不受目录过滤影响。
- **可视化监控**：详情页展示 LLM 调用审计（token 消耗去向）、放弃原因分布（冷却中/已沉淀/目标不明确/回放失败等）、失败样本队列。
- **安全边界**：先审后写模式可选；配置持久化防丢失；写入锁保护并发；识别词只增不删；写入失败自动回滚刚加的规则。

**配置项**

| 参数 | 说明 |
| --- | --- |
| `enabled` | 启用插件 |
| `confidence_threshold` | 兜底识别置信度阈值（默认 0.65） |
| `active_path` | 生效目录，默认 `/media/downloads` |
| `write_identifier` | 是否自动沉淀识别词（默认开） |
| `write_min_confidence` | 识别词写入置信度阈值（默认 0.7） |
| `cooldown_hours` | 同 title+path 冷却期，默认 24h |
| `review_mode` | 先审后写模式，默认关 |
| `notify_on_write` | 识别词写入成功时推送通知 |

**兼容性**

- MoviePilot：v2 插件规范
- 大模型：复用 MoviePilot 设定里的默认 AI（不需要单独配 key）
- 页面渲染：Vuetify（内置 PageRender）

### 当季新番与热门影视（MediaDiscovery）v1.3.4

按星期/年月分组展示当季新番与热门影视，支持多数据源、一键订阅、定时推送。

**主要功能**

- **双视图切换**：详情页顶部按钮一键切「番剧 / 影视」，各视图独立数据源配置。
- **番剧数据源（6 个）**：TMDB / Bangumi / 蜜柑 / 番组百科 / 番组百科每日更新 / 自动整合。
- **影视数据源（3 个）**：TMDB 热门影视 / 豆瓣热榜（TV+电影）/ 自动整合。
- **统一布局**：番剧按星期分组（周一~周日），电影按年月分组，组内按热度降序，前 4 项直接展示其余折叠。
- **一键订阅**：详情页点订阅按钮直接创建 MoviePilot 订阅；已订阅的按钮变绿色并标记「已订阅」。
- **定时推送**：同时推送番剧和影视两个视图的今日更新。
- **缓存优化**：订阅/取消订阅后自动清缓存，页面立即刷新；跨会话持久化当前视图选择。

**配置项**

| 参数 | 说明 |
| --- | --- |
| `anime_source` | 番剧数据源（auto / tmdb / bangumi / mikan / anibk / anibk_daily） |
| `movies_source` | 影视数据源（auto / tmdb_hot / douban_hot） |
| `refresh_interval` | 数据刷新间隔 |
| `notify_cron` | 定时推送 CRON |

**兼容性**

- MoviePilot：v2 插件规范
- 数据源：TMDB API / Bangumi API / 蜜柑站 / 番组百科 / 豆瓣（通过 MoviePilot 内置模块，无需 API Key）
- 页面渲染：Vuetify（内置 PageRender）

### 辅种查看（CrossSeedView）v1.3.7

跨下载器识别辅种，支持按媒体标题分组、筛选、批量删种与媒体库链接联动清理。

**主要功能**

- **跨下载器扫描**：统一扫描所有已配置的下载器（qBittorrent / Transmission / rTorrent），按分组键聚合。
- **两种分组模式**：`name_size`（种子名+大小，传统）/ `media_title`（按剥离后的番名分组，v1.3.0+）。
- **交互式筛选**：下载器、名称关键词、保存路径关键词、辅种数量区间、文件大小区间；条件持久化到插件配置。
- **组头三态多选**：未选/半选/全选三种视觉态，组头勾选整组切换，避免逐条点开面板。
- **批量删除**：仅删种 / 删种+文件 / 删种+文件+清库（后者联动删除媒体库软硬链、TransferHistory、DownloadHistory、发 DownloadFileDeleted 事件）。
- **翻译按钮**：按 TMDB 官方中文名优先 + 大模型兜底 + 持久化缓存，把种子名翻译成中文方便阅读。
- **性能与安全**：全量结果内存缓存，扫描一次全量算辅种；删除操作受安全开关保护，默认关闭。

**配置项**

| 参数 | 说明 |
| --- | --- |
| `group_mode` | 分组模式：`name_size` / `media_title` |
| `cron` | 定时扫描 CRON，默认 `0 4 * * *` |
| `allow_delete` | 详情页显示删除按钮（危险，默认关闭） |
| `notify` | 删种时发送通知 |
| `min_count` / `max_count` | 最小 / 最大辅种数 |
| `name_keyword` / `path_keyword` | 名称/路径关键词过滤 |

**兼容性**

- MoviePilot：v2 插件规范
- 下载器：qBittorrent / Transmission / rTorrent
- 页面渲染：Vuetify（内置 PageRender）

### 资源清理（MediaGarbageCleaner）v1.13.1

扫描媒体库与下载目录的各类垃圾，给出对应关系摘要与防误删机制，支持一次确认、批量清理。

**主要功能**

- **11 类垃圾扫描**：断链软链接 / 硬链接副本 / 重复文件 / 空目录 / 失败整理记录 / 孤儿 strm / 未整理文件 / 库内实体文件 / 下载库冗余副本 / 零字节文件 / 孤儿媒体目录。
- **对应关系面板**：页面顶部展示「下载目录 ↔ 媒体库」的一一对应状态，未引用下载源列出前 10 个文件名样例。
- **防误删机制**：保护路径 / 保护名称关键词 / 下载器在册豁免 / 保留期拒绝 / 删除前实时复核（副本存在、仍为 0 字节、确认无视频等）。
- **一次确认交互**：点击即执行，严谨性由删除前的实时校验保证。
- **批量删除通知**：分类汇总 + 联动清理明细 + 释放空间 + 已删除项列表（含超 10 项的省略收尾）。

**配置项**

| 参数 | 说明 |
| --- | --- |
| `enabled` | 启用插件 |
| `exclude_dirs` | 排除目录（不扫描） |
| `protect_name_keywords` | 保护作品名称（`\|` 分隔） |
| `dup_only_video` | 重复检测仅限视频（默认开） |
| `scan_*` | 11 类扫描的独立开关，默认按需开启 |
| `protect_minutes` | 新文件保护期，默认开 |

**兼容性**

- MoviePilot：v2 插件规范
- 页面渲染：Vuetify（内置 PageRender）
