# MoviePilot-Plugins

个人维护的 MoviePilot 第三方插件仓库。

## 订阅本仓库

在 MoviePilot 中打开 **设定 → 插件 → 插件市场**，添加以下地址：

```
https://github.com/zhuzhug/MoviePilot-Plugins
```

刷新后即可在插件市场中检索并安装本仓库提供的插件。

## 插件列表

### 辅种查看（CrossSeedView）

跨下载器识别辅种关系的可视化插件。以「种子名 + 文件大小」作为分组键，聚合当前所有下载器中的种子，帮助快速定位孤种、冗余种子与跨盘辅种情况，并可在开启安全开关后从界面直接删除单个辅种副本。

#### 主要功能

- **跨下载器辅种识别**：统一扫描所有已配置的下载器（qBittorrent / Transmission），按种子名与文件大小分组归并。
- **交互式筛选**：详情页顶部提供筛选表单，支持按下载器、名称关键词、保存路径关键词、辅种数量区间、文件大小区间进行过滤，条件持久化保存至插件配置。
- **可折叠分组卡片**：每个辅种组以可折叠面板展示，标题栏内联显示辅种数、单份体积、涉及的下载器；展开后列出全部辅种明细（下载器、保存路径、体积）。
- **可选删除**：在设置中显式开启「允许删除辅种（危险）」后，明细行提供「仅删种」与「删种 + 文件」两个操作；后端调用 MoviePilot 统一的 `remove_torrents` 通道，兼容各下载器差异。
- **定时与手动扫描**：默认按 CRON 定时全量扫描（`0 4 * * *`），详情页支持一键「立即重新扫描」。
- **性能与安全**：全量结果缓存在内存中，筛选与展示均在缓存上完成，避免频繁访问下载器；删除操作受安全开关保护，默认关闭。

#### 使用建议

- 首次使用建议保持「允许删除辅种」为关闭状态，先通过筛选熟悉本地辅种分布。
- 大量种子场景下（>10k），建议将 CRON 设为低峰时段，避免与站点刷流、同步任务冲突。
- 删除单个辅种前建议查看该分组内的做种数与来源下载器；**做种量越充足，删除单个副本对整体可用性的影响越小**。
- 云盘挂载路径下的种子建议通过路径关键词过滤后再进行清理，避免误删本地做种源。

#### 配置项

| 分组 | 参数 | 说明 |
| --- | --- | --- |
| 基础 | `cron` | 定时全量扫描表达式，默认 `0 4 * * *` |
| 基础 | `refresh_on_init` | MoviePilot 启动时是否立即执行一次扫描 |
| 基础 | `include_all_tags` | 是否包含无 MoviePilot 标签的种子 |
| 筛选 | `min_count` / `max_count` | 最小 / 最大辅种数（`max_count=0` 表示不限） |
| 筛选 | `downloader_filter` | 限定单个下载器 |
| 筛选 | `name_keyword` | 名称关键词，`\|` 分隔多个，不区分大小写 |
| 筛选 | `path_keyword` | 保存路径关键词，不区分大小写 |
| 筛选 | `size_min_gb` / `size_max_gb` | 单份体积区间（GB，`0` 表示不限） |
| 安全 | `allow_delete` | 是否在详情页显示删除按钮，默认关闭 |

#### 兼容性

- MoviePilot：v2 插件规范
- 下载器：qBittorrent、Transmission
- 页面渲染：Vuetify（内置 PageRender，无需前端链接）

# MediaGarbageCleaner（资源清理）

扫描媒体库中的垃圾文件，支持手动或批量清理。

## 主要功能

- **断链软链接扫描**：遍历媒体库目录，查找指向不存在目标的符号链接。
- **硬链接扫描**：查找 `st_nlink > 1` 的冗余硬链接（辅种/整理产生的副本）。
- **重复文件检测**：两阶段聚类（先按大小分组，再头部+尾部+大小签名），标注同组份数与建议保留。
- **空目录扫描**：查找媒体库中的空文件夹（可配置排除目录）。
- **失败整理记录**：查询数据库中状态为"失败"的 transfer 记录。
- **保护机制**：支持按路径排除目录、按名称关键词保护喜欢的作品（不扫描/不清理）。
- **批量操作**：支持全选/反选/清空选择，批量删除或仅删种。

## 使用建议

- 首次使用建议先扫描查看结果，确认无误后再执行清理。
- "保护作品名称"功能可避免误删喜欢的资源（如 `鬼灭之刃|权力的游戏`）。
- 排除目录功能可跳过不需要扫描的路径（如网盘挂载目录）。
- 重复检测默认仅针对视频类资源（占空间），可在设置中关闭以覆盖所有类型。

## 配置项

| 参数 | 说明 |
| --- | --- |
| `enabled` | 启用插件 |
| `exclude_dirs` | 排除目录列表（按地址过滤） |
| `dup_only_video` | 重复检测仅限视频类（默认开启） |
| `protect_name_keywords` | 保护作品名称（`|` 分隔，不区分大小写） |

## 兼容性

- MoviePilot：v2 插件规范
- 页面渲染：Vuetify（内置 PageRender）

### 当季新番（AnimeDiscovery）

发现当季新番，AI 增强简介，一键订阅追番。

#### 主要功能

- **三源自动整合**：TMDB + Bangumi + 蜜柑，自动去重合并，展示评分、海报、简介、蜜柑资源链接。
- **按星期分组**：番剧按首播日期（星期一~星期日）分组显示，蜜柑独有资源单独分区。
- **AI 增强简介**：开关控制，打开后用大模型重写简介为中文推荐语。
- **搜索与过滤**：支持番名搜索、仅看未订阅切换。
- **一键订阅**：点击订阅按钮直接创建 MoviePilot 订阅，自动追新集。
- **蜜柑跳转**：每部番剧附带蜜柑按钮，点击直达蜜柑站搜索资源。
- **自动刷新**：可配置每天上午 10 点自动刷新新番数据。
- **新番通知**：发现新番时推送通知提醒。

#### 配置项

| 参数 | 说明 |
| --- | --- |
| `data_source` | 数据源：`auto`（自动整合，推荐）/ `tmdb` / `bangumi` / `mikan` |
| `min_rating` | 最低评分过滤（0=显示全部） |
| `use_llm` | AI 增强简介开关（使用 MoviePilot 已配置的大模型） |
| `auto_refresh` | 每天 10 点自动刷新 |
| `notify_new` | 新番发现时推送通知 |

#### 兼容性

- MoviePilot：v2 插件规范
- 数据源：TMDB API / Bangumi API / 蜜柑站（mikanani.me）
- 大模型：需要在 MoviePilot 设定中配置 LLM（如 DeepSeek、MiMo 等）
